## Findings

1. The `largest block` of ~112 KB is what a save can use. The firmware's memory guard asks for 3x the largest remote
   file plus 8 KB; a *maximum-size* remote (about 48 KB of text) would need 152 KB and the save would be refused.
   Typical remotes (a few KB) are far below. To be revisited in B10 with the real firmware's heap numbers.
2. The board has a micro-USB connector, not USB-C. Nothing in the firmware depends on it.

## Flashing note

This board does not enter download mode by itself: BOOT must be held while the upload connects. Building first and then
uploading makes the window short (seconds); the first two attempts of `display_probe` failed when BOOT was not held at
the right moment.
